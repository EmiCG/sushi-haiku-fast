# HAIKU FAST SUSHI
Pagina web estatica para uso comercial con la finalidad de mostrar elementos importantes del menu y reedirigir al usuario a los medios de comunicacion oficiales para concretar un servicio de venta.

Cuenta con integracion de Api google-sheets para consultar datos sobre promociones en formati json y creacion objetos dinamicos.

Link al sitio web: [Haiku Fast Sushi](https://sushi-haiku-fast.netlify.app/).
